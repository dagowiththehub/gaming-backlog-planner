# Gaming Backlog Planner v1.2

## Nouveauté
Le Hall of Fame / Bilan annuel permet maintenant de rechercher un jeu dans RAWG.
Dans « Bilan annuel », choisir « Rechercher via RAWG », sélectionner un résultat PS4/PS5, puis compléter la durée jouée, la note et la date de fin. La validation ajoute le jeu au classement annuel et à la bibliothèque avec son illustration et ses informations RAWG.

La saisie manuelle reste disponible.

## Mise à jour
1. Faire un export JSON depuis l'application avant toute mise à jour.
2. Décompresser l'archive.
3. Remplacer les 7 fichiers dans la racine du dépôt GitHub.
4. Commit, attendre le déploiement GitHub Pages, puis actualiser le site dans Chrome et relancer la PWA.

La v1.2 conserve la clé locale `ps-backlog-v5` et les données existantes.
