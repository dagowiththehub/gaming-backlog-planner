Catalogue PS Plus

Catalogue PlayStation Plus

Le catalogue officiel varie selon le pays, l'abonnement et les dates d'entrée/sortie. Cette version prévoit une liste de jeux PS Plus que tu peux importer depuis un fichier CSV/JSON fiable, puis ajouter à ta bibliothèque.

Synchronisation officielle automatique : Sony ne propose pas d'API publique grand public documentée pour récupérer simplement tout le catalogue PS Plus de ton compte. On évite donc de dépendre d'une API non officielle fragile.

Consulter le catalogue officiel ↗

Aucun catalogue externe importé pour le moment.

Format CSV conseillé : title,platform,tier,cover. Format JSON : un tableau d'objets avec ces mêmes propriétés. L'import ne contacte aucun service externe.
